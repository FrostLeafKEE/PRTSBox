PRTSBox · 实时窗口翻译　使用说明
================================================

这是一个 Windows 上的实时屏幕翻译工具：抓取指定窗口的画面，识别其中的文字，
翻译后把译文盖回原来的位置，鼠标可以点穿，不影响你操作底下的窗口。

翻译用的是本地模型，装好之后完全离线运行，不联网、不消耗任何 API 额度。


一、第一次使用
------------------------------------------------

双击 PRTSBox.exe 打开。

点右上角「设置」→「本地模型」，依次下载两样东西：

  1. 推理运行时（llama.cpp）—— 选「Vulkan（推荐）」，约 33 MB
  2. 翻译模型 —— 选「标准（推荐）」，约 1.06 GB

两个都显示「已就绪」之后就可以用了。

  说明：运行时和模型没有打进压缩包里（模型太大不好传），首次使用时自动下载。

  如果下载慢或者失败，看同一个页面最上面的「下载源」：
    · 默认「自动」，会依次尝试国内源和官方源
    · 连不上就点「测试可达性」，它会实际请求每个源并列出结果和耗时
    · 也可以手动切成「仅国内源」或「仅官方源」

  国内源是腾讯自己的 ModelScope（约 20 MB/s）和 GitHub 加速；官方源是
  HuggingFace 和 GitHub。内容完全一样，只是走的路不同。


二、开始翻译
------------------------------------------------

  1. 在「目标窗口」下拉框里选要翻译的窗口（比如游戏、记事本、浏览器）
  2. 点「开始实时翻译」
  3. 切到目标窗口，按 F8 可以随时开关翻译

译文会显示在原文下方，鼠标可以直接点穿译文去操作底下的窗口。

停留在同一句话时，画面未变化会复用译文；识别框的小幅漂移不会移动译文。
相近文字变化会短暂确认后更新，所以只改了少数字符时可能稍晚一轮显示。
明显换页会直接处理，确认文字消失后会清除旧译文。


三、几个有用的选项
------------------------------------------------

「翻译引擎」
  可选择翻译平台、AI 大模型 API（OpenAI 兼容）、本地模型。
  翻译平台在「设置 → 翻译平台」中配置：
    · Azure Translator：订阅密钥、资源区域、接口地址
    · DeepL API：密钥及 Free / Pro 账户类型
    · 百度翻译：通用文本翻译 APP ID、密钥
  设置自动保存，密钥加密存储。配置后在主界面选择“翻译平台”及对应服务。

「显示桌宠 / 关闭桌宠」
  主界面按钮可以显示或隐藏 Frostbyte。按住桌宠左键可以拖动位置。
  右键桌宠可打开主窗口（最小化后也可恢复）、开启或停止翻译、关闭桌宠。
  开启翻译前先在主界面选择目标窗口。关闭桌宠不会停止正在运行的翻译；
  关闭主窗口则退出整个程序和桌宠。

「只识别窗口下方」
  文字类游戏通常只有底部的对话框需要翻译。勾上之后只识别窗口下方
  10~100% 的区域（默认 30%），可以避免把美术字、衣服上的字、场景里的
  文字也一起翻掉，识别速度也更快。建议先试 25~30%。

「已是中文的文本不翻译」
  默认开启。目标语言是中文时，识别结果本身是中文的行不会送去翻译，
  避免把原文改写一遍。目标语言选其他语言时这个选项不生效。

「文字识别后端」
  默认 ONNX Runtime，内存占用稳定。另一选项 OpenVINO 识别快约 2.6 倍，
  但长时间使用内存会持续增长，所以默认不用。

「同时显示原文」「显示耗时」
  前者在译文上方一并显示识别到的原文；后者在状态栏显示截图/OCR/翻译
  各阶段的耗时，排查卡顿的时候有用。

「译文可被截图 / 直播捕捉」
  默认不勾选。译文层用了 Windows 的捕获排除，默认不会出现在截图、录屏和
  直播画面里（OBS 之类的软件采集不到译文）。勾上之后这些工具就能拍到译文，
  适合把翻译效果直播出去或者录成视频。
  说明：识别读的是目标窗口自己渲染的画面，所以勾上不会导致译文被当成原文
  反复翻译。

「字号」「布局」
  译文大小可以 9~28 调节；布局有「原文下方」和「原文右侧」两种。
  如果译文比原文长很多、盖住了下面的内容，把字号调小会好一些。


四、已知现象（不是故障）
------------------------------------------------

· 有些窗口截出来是全黑的
  少数受保护的窗口（DRM 视频、部分带反作弊的游戏）不允许被截图，程序会
  跳过这一帧并保留上一次译文，不会把屏幕清空。

· 译文可能盖住下一行原文
  这是覆盖式翻译的固有限制——中文译文往往比英文原文占更多行。调小字号或
  改用「原文右侧」布局可以缓解。

· 内存占用
  跑起来后主程序约 1 GB、llama-server 约 1.9 GB，合计 3 GB 左右，长
  时间使用不会持续增长。不用时按 F8 关闭翻译，退出程序时模型进程会释放。

· 首次运行可能被 Windows 拦截
  程序没有代码签名，SmartScreen 可能提示「Windows 已保护你的电脑」。
  点「更多信息」→「仍要运行」即可；如果被 Defender 直接删除，需要把它
  加进白名单。


五、出问题了怎么办
------------------------------------------------

日志在程序目录下的 data\logs\ 里：

  prtsbox.log       运行日志（含下载试过哪些源）
  llama-server.log  翻译模型进程的输出
  crash.log         启动失败时的详细错误（如果有）

启动不了或者翻译不正常，把 prtsbox.log 发回给我就行。

也可以跑一次自检，它会逐项检查 OCR、下载、模型进程和翻译：

  在程序目录打开命令行，执行
      set PRTSBOX_SELFTEST=1
      PRTSBox.exe
  结果写进 data\logs\prtsbox.log。

  加上 download 参数（set PRTSBOX_SELFTEST=download）还会顺带验证
  下载和解压功能。


六、注意
------------------------------------------------

· 目前是测试版，用起来有任何别扭的地方都告诉我。
· 翻译模型是腾讯混元的 Hy-MT2，遵循其社区许可；自用没问题。
· 程序的所有数据（配置、模型、日志）都在程序自己的目录里，不会写到
  系统其他位置，删掉整个文件夹就等于彻底卸载。
